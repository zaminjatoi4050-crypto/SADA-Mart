# UI design status

JavaFX FXML shell with CSS-based light and dark tokens, scrollable sidebar, top bar, theme preference and page views for thirteen modules. These are development previews, not complete workflows. No fake business data is shown. Buttons for unfinished operations explicitly say the backend is unavailable; search/filters do not connect to data. A connection diagnostic is available but is not setup or authentication.

A real initial light overview was launched and inspected under Linux Xvfb at 1600x900 (`test-reports/gui-overview.png`). The other screens, navigation interactions, dark theme, keyboard accessibility, alternate resolutions and Windows visuals have not been inspected or tested. Scroll and spacing should be checked at all target resolutions. Premium full functionality and accessibility remain to be built.
